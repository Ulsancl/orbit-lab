# Orbit Lab 구조 관찰

이 앱은 고정된 태양 중력 중심 주위에서 질량 영향을 무시하는 시험입자 하나의 이상적 원·타원 궤도를 관찰합니다. 장면의 중심체와 시험입자는 원본 절차 생성 기호입니다. 구의 크기·표면 무늬·별 배경은 실제 천체 자료나 충돌 경계가 아닙니다.

물리 좌표 `(x,y)`를 `(x/AU,0,-y/AU)`로 옮기며 모든 궤도와 거리에는 같은 축척을 씁니다. 표시 공간의 1단위는 1 AU입니다. 궤도면의 법선은 +Y이고, 정면 보기는 이 방향에서 내려다봅니다. 카메라를 기울여 보는 것은 궤도 자체의 경사를 바꾸지 않습니다.

| 관찰 대상 | 확인할 관계 |
| --- | --- |
| 중심체와 시험입자 | 중심체의 중심은 한 초점에 고정되어 있습니다. 시험입자 구의 중심이 계산 위치입니다. 두 구는 관찰하기 쉽도록 확대했습니다. |
| 궤도와 두 초점 | 타원 중심은 중력 초점과 다릅니다. 다른 초점은 기하 보조점이며 두 번째 중력원이 아닙니다. 원에서는 두 초점과 중심체가 겹쳐집니다. |
| 장반경 a와 현재 거리 r | 장반경은 타원 중심에서 장축 끝까지입니다. 현재 거리는 중력 초점에서 시험입자까지라서 타원에서는 계속 바뀝니다. |
| 근일점과 원일점 | 타원에서 가장 가까운/먼 위치입니다. 원궤도는 모든 곳의 거리가 같아 +X 표식은 기준 위치일 뿐입니다. |
| 속도 벡터 | 시험입자 중심에서 시작하는 접선 방향의 화살표입니다. 1 km/s를 0.01 AU의 표시 길이로 변환합니다. 물체가 그 거리만큼 순간 이동한다는 뜻이 아닙니다. |
| 같은 시간의 면적 | 평균근점이각 0°와 180°에서 각각 주기의 1/12 동안 쓸린 곡선 부채꼴입니다. 같은 현재 궤도의 두 구간이며 다른 궤도끼리 면적이 같다는 설명이 아닙니다. |

현재 궤도는 청록 실선, 보관 궤도는 자주 점선과 빈 표식입니다. 보관 궤도와 위치는 보관한 상태에 고정되어 있습니다. 두 궤도는 크기를 따로 정규화하지 않습니다. 전체 보기는 보이는 현재·보관 구조를 함께 담고, 일반 조건 변경·선택·창 크기 변경은 사용자가 맞춘 카메라를 유지합니다.

궤도선은 모델이 내보내는 512개 시간 구간의 좌표로 만들고 마지막 점을 닫습니다. 두 면적 표시는 각각 1024개 구간의 실제 곡선 경계를 초점과 연결한 삼각형 부채로 그립니다. 화면용 Float32 기하의 면적은 해석값과 작은 분할 오차가 있습니다. 단 하나의 시작·끝점 삼각형을 정확한 쓸린 면적으로 대체하지 않습니다. 이 표본화는 모형의 궤도 해석이나 보존량을 다시 계산하는 별도 물리가 아닙니다.

부품 이름표는 화면에서 수평으로 유지되고 실제 위치에 연결됩니다. 선택은 설명과 강조를 바꾸며, 명시적인 집중 보기만 카메라를 이동합니다. 표시를 끈 보조 구조는 관찰 레이어를 켜서 확인할 수 있습니다. 구의 광택이나 배경 별은 시간에 따라 자동으로 움직이는 추가 물리 현상이 아닙니다.

태양 GM과 AU는 [NASA/JPL의 천문역학 상수](https://ssd.jpl.nasa.gov/astro_par.html)를 따릅니다. 타원·초점·같은 시간의 면적·공전주기의 관계는 [NASA의 케플러 법칙 설명](https://science.nasa.gov/learn/basics-of-space-flight/chapter3-3/)에서 확인할 수 있습니다. 실제 날짜의 천문력, 다른 천체의 섭동, 추진·충돌·탈출은 이 모형의 범위에 포함하지 않습니다. 외부 사진이나 텍스처는 사용하지 않았습니다.
