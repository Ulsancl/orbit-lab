# 문제 보고

[문제 보고](https://github.com/Ulsancl/orbit-lab/issues/new/choose)에 앱 버전, Windows 버전, GPU, 화면 배율·해상도, 재현 순서와 기대/실제 결과를 적어 주세요. 긴반지름 a(AU), 이심률 e, 진행률 t/T, 시간 속도와 현재/보관 궤도 중 어느 것인지도 필요합니다.

정확한 날짜의 실제 행성 위치·다체 상호작용·충돌·추력·궤도 전이·탈출은 이 모형의 지원 범위가 아닙니다. 수치 문제라면 표시 단위와 확인한 공식·출처를 함께 적어 주세요. 원궤도에는 유일한 근일점·원일점이 없고 t/T는 기하학적인 각도가 아닙니다.

손상되거나 더 새로운 버전인 파일은 원문을 별도로 보관하고 덮어쓰지 마세요. 공유 전에 비교 이름·파일 내용·개인 경로·진단 로그를 확인하세요. 전체 사용자 프로필을 올릴 필요는 없습니다. 문제 보고는 응답 시간·모든 기기 호환성·유료 유지보수 계약을 보장하지 않습니다.
