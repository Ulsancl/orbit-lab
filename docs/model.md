# Orbit Lab의 궤도 모형

Orbit Lab은 고정된 태양의 뉴턴 중력 아래 시험입자 하나가 도는 이상적인 원·타원 궤도를 계산합니다. 중심체의 움직임에 영향을 주지 않을 만큼 입자의 질량이 작다고 가정합니다. 실제 날짜의 천체 위치나 우주선 항법을 예측하는 프로그램은 아닙니다.

## 상수와 지원 범위

모델 버전은 `orbit-kepler-1`입니다. 계산에는 다음 고정값을 사용합니다.

| 항목 | 값 |
| --- | --- |
| 1 AU | 149597870700 m |
| 1 day | 86400 s |
| 태양 중력계수 μ | 1.32712440041279419 × 10²⁰ m³/s²의 JavaScript Number 표현 |
| 긴반지름 a | 0.5..2 AU, 기본 1 AU |
| 이심률 e | 0..0.8, 기본 0.35 |

상수는 [JPL Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html)의 AU·day·heliocentric GM을 사용합니다. 해당 GM 표의 근거는 DE440/441입니다. G와 태양 질량을 별도로 곱하거나 상수를 온라인에서 갱신하지 않습니다.

지원 범위에서 중심체와의 거리는 항상 0.1 AU 이상이며, `1−e cos E`는 0.2 이상입니다. e=0인 원에서는 모든 위치의 거리가 같으므로 +x는 임의의 기준 방향입니다. 특정 한 점만 근일점이라고 해석하지 않습니다.

## 저장되는 상태와 시간

```js
{
  config: { semiMajorAxisM, eccentricity },
  meanAnomalyRad
}
```

M=`meanAnomalyRad`은 0 이상 2π 미만인 평균근점이각입니다. M은 시간에 비례하며, 입자의 실제 위치 각도인 진근점이각과 일반적으로 다릅니다. 화면의 진행률 t/T는 M/(2π)입니다.

모형은 누적 경과시간이나 회전 횟수를 별도로 저장하지 않습니다. `timeSinceReferenceS=M/n`은 **현재 한 주기 안에서 기준점을 지난 시간**으로 한 바퀴마다 0으로 돌아옵니다. e>0이면 기준점은 근일점, 원에서는 +x 방향입니다. 저장 파일에는 좌표·속도·시간 같은 파생값 대신 위 입력을 보관합니다.

모든 궤도에 같은 관찰 배율을 적용합니다. 기본은 화면 1초에 모형 15일이며 5·15·30일을 선택할 수 있습니다. 배율은 관찰 설정이며 물리 상태에 포함되지 않습니다. 예를 들어 기본 배율에서 a=1 AU의 한 바퀴는 약 24.35초, a=2 AU는 약 68.87초입니다. 궤도별 화면 주기를 같게 맞추지 않습니다.

a 또는 e를 바꾸는 것은 같은 M에서 새로운 이상 궤도를 선택하는 동작입니다. 연속적인 추력 기동을 계산한 것이 아니므로 위치·속도·에너지가 즉시 달라질 수 있습니다. 조건 변경과 명시적인 공전 위치 이동은 일시정지하며, 파일을 다시 열 때도 정지 상태로 복원합니다.

## 계산식과 수치 해법

궤도면에서 중심체는 원점, 근일점 방향은 +x이며 운동은 +x에서 +y로 향합니다. 모든 각은 라디안, 거리·속도·시간은 SI입니다.

```text
b = a sqrt(1−e²)
n = sqrt(μ/a³), T = 2π/n
M = E − e sin E
q = 1−e cos E
x = a(cos E−e), y = b sin E, r = aq
vx = −a sin E · n/q, vy = b cos E · n/q
ν = atan2(y,x), [0,2π)로 정규화
rp = a(1−e), ra = a(1+e)
vp = sqrt((μ/a)(1+e)/(1−e))
va = sqrt((μ/a)(1−e)/(1+e))
ε = −μ/(2a), h = sqrt(μa(1−e²))
면적속도 = h/2, 전체 타원 면적 = πab
```

E는 편심근점이각입니다. 방정식과 궤도면 좌표의 원형은 [JPL Keplerian elements 문서](https://ssd.jpl.nasa.gov/planets/approx_pos.html)에 있습니다. JPL 문서의 도 단위 방정식은 여기서 라디안으로 환산했으며, 해당 문서의 행성표와 천체력은 사용하지 않습니다.

solver는 반주기 대칭과 해의 bracket을 사용합니다. 최대 64회 안에서 Newton 후보가 bracket 밖이거나 유효하지 않으면 이분법으로 전환하고, 12회 이후에는 이분법만 사용합니다. 최종 수렴·유한값·잔차를 검사하며 실패하면 값을 꾸며 반환하지 않습니다. e=0과 M=0·π는 직접 처리합니다. 매 위치를 현재 M에서 계산하므로 위치 적분의 누적 오차로 궤도가 붕괴하지 않습니다.

`advanceExperiment`의 단일 시간 이동 범위는 0..3155760000초입니다. 시간을 주기로 먼저 축약한 뒤 M을 진행시킵니다. 이 100 Julian years 상한은 API의 유한 입력 경계이며 실제 천체 예측 유효기간을 뜻하지 않습니다. 부동소수점 계산은 무오차가 아니므로 여러 프레임의 결과를 비교할 때에는 원형 각도 오차를 사용합니다. 재생에서는 기준 상태와 단조 시간에서 전체 진행량을 계산해 불필요한 작은 덧셈 누적을 줄입니다.

에너지 ε는 **J/kg**, 각운동량 h는 **m²/s**인 단위 질량당 값입니다. 시험입자 질량을 입력하지 않으므로 총에너지 J나 총각운동량을 예측하지 않습니다.

## 곡선 면적과 표시 표본

같은 궤도의 같은 시간 간격은 같은 쓸린 면적을 만듭니다. 이는 중심체에서 두 위치로 향하는 반지름과 그 사이 **실제 궤도 곡선**이 감싼 면적입니다. 두 끝점을 직선으로 연결한 삼각형의 면적이 같다는 뜻은 아닙니다. [NASA의 케플러 법칙 설명](https://science.nasa.gov/learn/basics-of-space-flight/chapter3-3/)과 [OpenStax §13.5](https://openstax.org/books/university-physics-volume-1/pages/13-5-keplers-laws-of-planetary-motion)에 같은 시간의 면적 및 각운동량 보존 관계가 설명되어 있습니다.

구간의 정확 면적은 `A=(h/2)Δt`입니다. 첫 판의 두 표시 구간은 M=0..π/6과 π..7π/6이며, 각각 Δt=T/12, 면적 πab/12입니다. 서로 다른 a/e 궤도 사이의 같은 시간 면적까지 같다는 뜻은 아닙니다.

`sampleOrbit`과 `getSweptSector`는 같은 해법에서 시간 등분 표본을 생성합니다. 기본 분할 256, 허용 분할 16..2048, 반환 점 수는 분할 수+1입니다. 완전한 한 바퀴의 마지막 좌표는 첫 좌표와 정확히 같게 닫고 별도 객체로 반환합니다. 0초 구간은 같은 위치의 유한 표본들과 면적 0을 반환합니다. 주기를 넘는 구간은 끝의 감긴 M을 빼지 않고 양의 구간 시간으로 정의합니다.

화면의 면은 유한한 삼각형들로 곡선을 근사하므로 수치 면적과 미세하게 다를 수 있습니다. 표본이 늘 때 근사 면적이 정확값으로 수렴하는지 검사합니다. 좌표는 공통 AU 축척을 사용하지만 태양·입자 구와 속도 화살표는 관찰용 표시입니다. 표식 표면은 충돌 경계가 아닙니다.

## 독립 기준값과 API 검증

| 조건 | 계산 기준값 |
| --- | --- |
| a=1 AU인 원 | 주기 365.2568983272364일, 속력 29.784691834309108 km/s |
| a=.5 / 2 AU | 주기 129.1378148411771 / 1033.1025187294167일, 비율 8 |
| a=1 AU, e=.6 | 근·원일점 .4 / 1.6 AU, 속력 59.569383668618215 / 14.892345917154554 km/s |
| 위 타원의 E=π/2 | M=π/2−.6, 위치 (−.6,.8) AU |
| 위 타원의 M=π/2 | E=2.091328966032915 rad |
| 위 타원의 T/12 | 면적 .20943951023931953 AU² |

주기·축상 값은 닫힌 식으로, 일반 E는 별도의 이분법으로 비교합니다. 반환 좌표·속도에서 에너지·각운동량을 다시 계산하고, 중심차분으로 속도·중력 가속도를 확인합니다. 곡선 면적은 선분 cross product 합의 수렴으로 확인합니다. 반환된 상수 필드끼리 같은 식을 비교하는 검사만으로 끝내지 않습니다.

`normalizeConfig`와 `createExperiment`는 현재 UI의 잘못된 live 입력을 기본값·범위 제한으로 보정합니다. `assertConfig`, `assertExperiment` 및 계산 함수는 정확한 필드, 유한 숫자와 지원 범위를 요구하며 문자열 변환, 음의 0, 미지원 필드를 거부합니다. `wrapMeanAnomalyRad`는 유한 각을 정규화하는 helper로 음의 0을 양의 0으로 만들지만 비유한 값은 거부합니다. 매우 큰 누적 각도의 임의 정밀도를 보장하지 않으므로 무제한 누적 각도를 상태로 보관하지 않습니다. 기본 상수는 동결되어 있고 반환된 설정·좌표·표본은 원본과 독립적입니다.

검사 명령: `node --test tests/model.test.mjs`. 검증 환경과 릴리스 결과는 해당 릴리스 기록을 따릅니다.

## 생략한 현상

태양의 반동, 다른 천체, 상대론과 궤도 세차, 항력·추력, 충돌·탈출, 궤도 전이, 실제 달력과 천체력은 계산하지 않습니다. 고정된 평면을 3D 카메라로 관찰하는 것이며 궤도면의 동역학을 계산하지 않습니다. 원형·타원형 케플러 운동을 비교하는 교육용 모형의 범위에서 사용합니다.
