# Orbit Lab 상세 관찰의 계산 기준

이번 상세값은 기존 `orbit-kepler-1` 해석 궤도의 현재 위치와 속도를 읽어 계산합니다. 궤도 solver, 저장 schema 1, 보관한 비교 실험에는 새 상태를 추가하지 않습니다. 같은 입력으로 언제든 재현할 수 있는 관찰값이며, 원래 프로젝트의 물리 조건과 위상을 변경하지 않습니다.

## 속도 성분과 중력 가속도

궤도면에서 중심체는 원점, 진행 방향은 +x에서 +y입니다. 위치 벡터를 **r**, 속도 벡터를 **v**, 거리 크기를 r라고 하면 다음과 같습니다.

```text
er = (x/r, y/r), eθ = (−y/r, x/r)
h = x vy − y vx
vr = (r·v)/r = n a² e sin(E)/r
vθ = h/r
v = vr er + vθ eθ
γ = atan2(vr, vθ)
acceleration = −μ r/r³
ar = −μ/r², aθ = 0
```

방사 속도 `vr`는 초점에서 멀어지면 양수, 가까워지면 음수입니다. 횡방향 `vθ`는 **반지름에 수직인 방향**입니다. 타원에서 전체 속도 **v**가 궤도 접선이며 `vθ` 혼자 궤도 접선이라는 뜻은 아닙니다. 비행 경로각 γ는 횡방향에서 바깥쪽으로 기운 각도입니다.

구현은 두 큰 내적 항의 상쇄를 피하려고 같은 식을 인수분해한 `n a² e sin(E)/r`로 `vr`를 계산합니다. 원 `e===0` 또는 정확한 근·원일점 `M===0`, `M===π`에서만 0을 직접 반환합니다. 작은 이심률이나 작은 속도를 임의의 문턱으로 0에 붙이지 않습니다. 표시 자릿수로 반올림된 숫자는 상태 분류 기준이 아닙니다.

방사 가속도와 거리의 두 번째 미분은 다릅니다. 회전하는 극좌표 기저 때문에 `d²r/dt² = ar + vθ²/r`입니다. 따라서 원에서 거리가 일정하여 `d²r/dt²=0`이더라도 원점을 향한 실제 가속도는 0이 아닙니다. 가속도는 항상 중력 초점을 향하며 추가 추력·저항을 포함하지 않습니다.

`sqrt(μ/r)`와 `sqrt(2μ/r)`는 **현재 거리**의 원궤도 속력과 탈출 속력입니다. 전체 속력과 비교하는 진단값이며 차이를 기동 Δv나 연료량으로 해석하지 않습니다. 기존 모델은 원·타원만 계산하며 탈출 궤도나 궤도 전이를 새로 시뮬레이션하지 않습니다. 원궤도 속력과 에너지의 물리적 정의는 [OpenStax §13.4](https://openstax.org/books/university-physics-volume-1/pages/13-4-satellite-orbits-and-energy)를 따릅니다.

## 에너지와 각운동량

```text
specific kinetic energy K = (vx² + vy²)/2
specific potential energy U = −μ/r       (infinity is the zero reference)
specific total energy ε = K + U
reference ε = −μ/(2a)
specific angular momentum h = x vy − y vx
reference h = sqrt(μ a (1−e²))
areal velocity = h/2
```

에너지는 J/kg, 각운동량은 m²/s입니다. 입자 질량을 입력하지 않으므로 총에너지 J나 총각운동량 kg·m²/s는 알 수 없습니다. 화면에서 MJ/kg, km²/s로 바꿔 보여도 같은 단위 질량당 양입니다. 잠재 에너지의 기준은 무한대이며 지원하는 묶인 궤도의 총에너지는 음수입니다.

보존 잔차는 현재 반환 좌표·속도에서 재구성한 값에서 기존 해석 기준을 뺀 부호 있는 차이입니다. 상대 잔차는 에너지의 경우 `δε/|εref|`, 각운동량은 `δh/href`입니다. 이 작은 차이는 부동소수점 연산 수준의 수치 일치 검사입니다. 누적 에너지 손실, 실험 오차 또는 실제 천체 예측 정확도가 아닙니다. 서로 다른 a·e를 선택한 전후의 에너지가 보존된다고 주장하지 않습니다.

## 세 가지 각도와 주기 안의 시간

`M`은 시간에 비례하는 평균근점이각, `E`는 타원 중심의 반지름 a 보조 원에서 재는 편심근점이각, `ν`는 중력 초점에서 입자를 향하는 진근점이각입니다. 기존 케플러 관계 `M=E−e sin(E)`를 사용하며 각 정의는 [JPL의 Keplerian elements 문서](https://ssd.jpl.nasa.gov/planets/approx_pos.html)의 궤도면 좌표와 일치합니다. JPL의 실제 천체 위치 근사표를 이 모형에 사용하지는 않습니다.

```text
dM/dt = n
dE/dt = n a/r
dν/dt = h/r²
cycleElapsedS = M/n
timeToPeriapsisS = (2π−M)/n, except M=0 gives 0
timeToApoapsisS = forward angle from M to π, divided by n
```

시간은 현재 한 주기 안의 위치입니다. 누적 회전 수, 실제 날짜, 실행 후 총 경과시간이 아닙니다. 목표 위치에 바로 있으면 남은 시간은 0입니다. 그 위치를 조금 지난 직후에는 다음 같은 위치까지 거의 한 주기가 남습니다. 주기 경계의 이러한 시간 점프는 정상이며 위치·속도·에너지는 연속입니다. 최하위 비트에 가까운 위상에서는 남은 시간이 한 주기와 같은 부동소수점 값으로 반올림될 수 있습니다.

정확히 `e=0`인 원에는 유일한 근일점·원일점이 없습니다. 따라서 해당 남은 시간은 `null`이며 화면은 ‘구별 없음’으로 표시합니다. 기준 +X 위치에서의 `M/n` 자체는 계속 유효합니다. 매우 작은 **양의** e는 여전히 타원이며 작은 방사 속도와 고유한 두 apsis를 유지합니다. 관찰 재생 배율·카메라·정지 상태는 이 물리적 변화율을 바꾸지 않습니다.

## API와 부품 관찰

`orbitDetail(snapshot)`는 다음 분리된 SI 그룹을 반환합니다.

| 그룹 | 주요 값 |
| --- | --- |
| `velocity` | 부호 있는 `radialMps`, `transverseMps`, 각 성분 벡터, 속력, 비행 경로각, 원궤도·탈출 속력 |
| `acceleration` | 실제 가속도 벡터, 크기, 방사·횡방향 성분 |
| `energy` | 운동·퍼텐셜·총에너지, 해석 기준, 부호 있는 절대·상대 잔차 |
| `momentum` | 벡터에서 재구성한 단위 질량당 각운동량, 해석 기준·잔차, 면적속도 |
| `phase` | M·E·ν, 각각의 물리 각속도, 주기와 한 주기 안 경과시간 |
| `apsides` | 고유한 두 apsis 존재 여부, 정확 위치 여부, 남은 시간·거리 |
| `geometry` | a·b·ae, 초점 사이 거리, 타원 중심·다른 초점 좌표 |

`describeOrbitDetail(partId, snapshot, detail?)`은 기존 열 개 부품에 `{facts, note}`를 제공합니다. 각 facts 행은 `{label, value, unit, digits}`이며 최대 여섯 행입니다. 설명용 부품도 실제 물리량과 기하학적 의미를 구분합니다. 다른 초점에는 별이나 중력원이 없고, 표식 구의 크기는 실제 천체 반지름이 아닙니다. 두 부채꼴의 정확 면적은 각각 `πab/12`이며, 같은 궤도에서 `T/12` 동안 쓸린 곡선 면적입니다.

detail 모듈은 `model.js`만 불러오며 3D geometry·renderer·저장 schema를 가져오지 않습니다. strict 원래 입력과 그에 대응하는 snapshot을 확인하고 입력을 보정하지 않습니다. 반환 벡터는 입력에서 분리된 객체입니다. detail 전체나 새 임시 관찰 상태를 기존 실험·비교 레코드에 기록하지 않습니다.

## 독립 검증

`node --test tests/detail-model.test.mjs`는 다음을 확인합니다.

- 원과 e=.6, E=π/2의 닫힌 기준값; 지원 범위 양 끝의 근·원일점 속력과 각속도 비율
- 실제 Cartesian 내적·외적, 두 속도 벡터의 재구성·직교성과 중력 방향
- e=1e−16까지 작은 양의 이심률 보존, 정확 apsis와 근처 위상의 구분
- 물리 시간 중심차분으로 거리·E·ν 변화율, 가속도, 운동·퍼텐셜 에너지 교환 확인
- 거리 2차미분과 방사 가속도의 좌표계 항 구분
- 별도 시간 구적법으로 한 주기 평균 운동·퍼텐셜 에너지와 ν의 총 2π 회전 확인
- 이심률 벡터·각운동량·에너지 보존, 주기 경계 연속성, a 변화의 차원별 스케일 법칙
- 남은 시간으로 원래 solver를 진행했을 때 실제 목표 apsis 도착
- 열 개 부품의 단위 환산, strict 입력 거부, 원본/보관/저장 문자열 불변과 반환 객체 분리

유한차분은 절단 오차와 반올림 오차가 있는 독립 근사이므로 무오차 비교를 요구하지 않습니다. 기존 solver 검사를 대신하지 않고 함께 실행합니다.
