# 로컬 자료와 개인정보

설치 앱은 궤도 계산과 화면에 필요한 기능을 로컬에 포함합니다. 계정·광고·원격 분석·자동 오류 전송 기능을 구현하지 않습니다. 앱 화면의 HTTP/HTTPS 요청과 외부 창은 차단합니다. 개발 의존성·검사 도구 준비는 별도이며 인터넷을 사용할 수 있습니다.

파일 열기·저장은 사용자가 선택한 로컬 파일을 대상으로 합니다. 자동 저장·창 위치·실행 로그는 Orbit Lab 로컬 프로필에 남습니다. 비교 이름, 궤도 조건, 공전 위치, 관찰 시점과 배율은 실험 파일에 포함됩니다. 원문 복구는 사용자의 선택으로 로컬 파일에 내보냅니다.

문제 보고 자료에는 개인 경로나 환경 정보가 포함될 수 있습니다. 재현에 필요한 작은 자료만 남기고 비교 이름·로그·스크린샷을 확인한 뒤 직접 공유하세요. 앱이 자료를 자동 제출하지 않으며 자동 저장은 외부 백업을 대신하지 않습니다.
