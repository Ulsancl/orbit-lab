# 실험 파일과 원문 보호

`.orbit.json`은 `type: orbit-lab-project`, `schemaVersion: 1`, `modelVersion: orbit-kepler-1`인 JSON입니다. 실험은 `config:{semiMajorAxisM,eccentricity}`와 `meanAnomalyRad`를 담습니다. 비교 기록은 별도 이름과 같은 구조의 실험을 보관합니다.

관찰 정보에는 표시 플래그·선택 대상, 카메라, `daysPerSecond` 5·15·30을 보관합니다. 카메라는 1 단위가 1 AU인 화면 공간 좌표이며 물리 계산의 미터 좌표와 다릅니다. 표시용 좌표의 절댓값은 30 이하, 카메라 거리는 0.2~40, 확대는 0.25~4입니다. 카메라가 null이면 저장된 수동 시점이 없다는 뜻입니다.

위치·속도·에너지·경로 배열은 입력에서 다시 계산합니다. 벽시계, 누적 공전 횟수, 재생 여부, 안내 완료 이력과 그래프의 현재/보관 표시 선택은 저장하지 않습니다. 가져오기와 재시작은 항상 정지 상태로 복원합니다.

파일 입력은 엄격하게 검사합니다. 조건 범위 초과, 알 수 없는 필드·버전, 문자열 숫자, 유한하지 않은 수치, 음의 0을 자동 보정해 받아들이지 않습니다. UTF-8 10 MiB 한도와 맨 앞의 BOM 한 개를 지원합니다. live 입력 기본값을 정리하는 API와 파일 검증은 별도입니다.

브라우저 자동 저장 키는 `orbit-lab-project-v1`입니다. 읽을 수 없거나 더 새로운 형식의 자동 저장 원문은 유지하고 원문 내려받기를 제공합니다. 실패한 가져오기는 현재 관찰을 바꾸지 않습니다. 새 실험의 되돌리기는 현재 세션에서만 사용할 수 있습니다.

데스크톱은 선택한 일반 파일만 읽고, 저장 시 같은 폴더의 새 임시 파일에 기록·동기화·닫기를 마친 뒤 이름을 바꿉니다. Windows의 일시적인 공유 잠금에는 제한된 재시도를 하고 매번 대상 경로를 다시 검사합니다. 재시도가 끝나도 실패하면 기존 대상 파일을 삭제하지 않으며 자신이 만든 임시 파일만 정리합니다. 이것은 전원 장애나 저장 장치 고장에 대한 별도 백업을 대체하지 않습니다.
